تعديل الإعلانات والمواسم بدون APK: عدّل الملف www/live.json في المشروع ثم شغّل: bash ./push.sh "إعلان"

إعلان (يظهر في الرئيسية حتى يغلقه المستخدم):
 "announce": [ { "id": "a1", "title": "العنوان", "body": "النص", "link": "#/x/hadith", "btn": "افتح", "from": "2026-11-01", "to": "2026-11-30" } ]
 - id لازم يكون فريدًا لكل إعلان. from و to اختياريان (بصيغة سنة-شهر-يوم).

موسم مخصص (يغيّر شريط الرئيسية):
 "seasons": [ { "id": "ramadan", "title": "رمضان كريم", "sub": "نص قصير", "from": "2027-02-08", "to": "2027-03-09" } ]
 ids الألوان المدعومة: ramadan, hajj, eid, friday

ما الجديد:
 "whatsnew": [ { "title": "العنوان", "date": "نوفمبر 2026", "items": ["سطر 1", "سطر 2"] } ]
 أول عنصر هو الأحدث.
